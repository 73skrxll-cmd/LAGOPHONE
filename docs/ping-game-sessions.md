# Игровая сессия «Пинг», 0.15.0-beta.1

Целевые ОС: Windows 10 и 11 x64, Windows PowerShell 5.1. Electron остаётся системным компонентом; браузерный предпросмотр не управляет Windows и не показывает тестовые значения.

## Как пользоваться

1. Закрой игру. Выбери PUBG, Fortnite или Escape from Tarkov. Установки Steam/Epic/BSG определяются по реестру, манифестам и проверенным файлам. Если установка не найдена — «Указать игру».
2. При желании один раз разреши паузу собственных фоновых загрузок BITS в настройках. Загрузки Steam и Epic этим API не управляются. Скорость тарифа необязательна; без неё занятость WAN не вычисляется.
3. «Оптимизировать и запустить»: два одинаковых измерения по 20 ICMP-запросов до одного контрольного IP и шлюза, доступная пауза BITS по согласию, затем открытие игры через Steam/Epic. Tarkov открывает BSG Launcher; универсального документированного способа нажать «Играть» без участия пользователя не найдено.
4. Пока игра открыта, выполняются только чтение сетевых счётчиков, проверка процесса и диагностические ICMP-запросы. Завершение наблюдаемого процесса игры, «Остановить», закрытие приложения или запуск после сбоя возвращают поставленные приложением паузы BITS. Игра не завершается принудительно.

## Что измеряется

- Активный IPv4-маршрут: default route + interface metric, статус адаптера, шлюз, идентификатор интерфейса. Не догадка по первому сетевому устройству.
- Скорость текущего обмена: разности счётчиков ReceivedBytes/SentBytes за фактический интервал. Это трафик адаптера, включая LAN, а не измерение скорости тарифа или доказательство заполненного WAN.
- RTT до роутера и контрольного узла 1.1.1.1/8.8.8.8 показаны отдельно с адресом, методом и количеством ответов. Неответы названы «Без ответа ICMP», а не потерями игровых UDP-пакетов. Отсутствие ответа не блокирует запуск игры.
- Игровой UDP-сервер автоматически не определяется: Get-NetUDPEndpoint не даёт достоверной привязки удалённого игрового сервера и его RTT. Значение «В игре» — «Нет данных». Ни ICMP до Cloudflare, ни TCP до API лаунчера не подставляются вместо пинга игры.
- Среднее абсолютное изменение RTT между успешными ответами — показатель колебаний; это не синхронизированный игровой jitter. При смене интерфейса или цели сравнение не засчитывается.
- Рост задержки под нагрузкой выявляется пассивно только при указанных скоростях тарифа и наличии хотя бы пяти загруженных и пяти незагруженных успешных отсчётов одной серии. Это наблюдаемая связь, не причинное доказательство bufferbloat. Искусственный нагрузочный трафик не создаётся.
- Wi-Fi/колебания шлюза/нагрузка и внешний маршрут разделены на наблюдаемые факты и гипотезы. Уровень сигнала доступен только когда системный вывод однозначен. Конкретный проблемный hop/провайдер без доказательства не называется.

## Обоснованные действия и ограничения

Единственное временное системное изменение — Suspend-BitsTransfer для активных/очередных BITS-заданий текущего пользователя после явного согласия. Оно может уменьшить конкуренцию за канал, если такие передачи есть. При отсутствии подходящих задач приложение честно выполняет только диагностику и запуск; проценты ускорения и прирост игрового пинга не обещаются. Пауза BITS не управляет Steam/Epic, браузерными скачиваниями и заданиями другого пользователя/SYSTEM. Программа не завершает чужие процессы, не отключает защиту, не читает память игр, не меняет DNS/реестр/MTU/сетевой стек.

Параметры и пути хранятся в `ping-game-settings.json` профиля приложения. Журнал `ping-game-journal.json` создаётся до паузы, отмечает намерение перед каждой операцией; восстанавливаются только отмеченные задания, которые по-прежнему приостановлены. Уже приостановленные пользователем задания не затрагиваются. Частичная ошибка восстановления сохраняет оставшиеся задания и блокирует новую сессию. Отдельный процесс PowerShell следит за PID и временем запуска родителя и восстанавливает задачи после аварии; восстановление также повторяется при следующем запуске. При аварии Windows/сбое службы BITS восстановление возможно после следующего запуска/доступности службы. Таймаут защиты — 12 часов. Не требуются права администратора: BITS используется только в текущем профиле.

Поддерживается IPv4-диагностика; при отсутствии IPv4/недоступных cmdlets показатели отсутствуют, но запуск через лаунчер остаётся доступен. Не гарантируются доступность ICMP у роутера, точность определения Wi-Fi на всех драйверах и автоматическое обнаружение нестандартных установок. Если игра не появилась за десять минут, подготовленная сессия прекращается и фоновые загрузки возобновляются.

## Бесплатная внешняя маршрутизация

Для реального изменения внешнего маршрута необходим удалённый узел и туннель. Локальный алгоритм не сокращает путь у провайдера.

Изучен бесплатный потребительский Cloudflare WARP: режим полного трафика переносит UDP и использует инфраструктуру Cloudflare; DNS-only и локальный HTTP/SOCKS-прокси не являются заменой игровому UDP-туннелю. WARP+ — платный продукт и не используется. Потребительский WARP не требует входа в личный аккаунт, но регистрирует устройство у провайдера и требует принятия его условий; это не решение без внешних обязательств. Прямой доступ к актуальным юридическим условиям из окружения вернул 403, поэтому пригодность условий для встраивания/распространения не утверждается.

В предыдущем реальном Windows-тесте контрольного TCP-соединения до Discord медианы составили 13,64 → 15,73 → 13,79 мс. Это не тест PUBG/Fortnite/Tarkov и не доказательство свойств WARP на сети пользователя. Подтверждённого бесплатного улучшения для выбранных игр нет. Поэтому автоматическая установка/активация WARP удалена из обычного сценария; прежние WARP IPC не регистрируются и не доступны через preload. Внешние маршруты во время матча не переключаются. Случайные прокси, чужие ключи, подписки и пробные периоды не применяются.

## Источники

Проверены 2026-11-02:

- Microsoft [Get-NetRoute](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-netroute), [Get-NetIPInterface](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-netipinterface): таблица маршрутизации и метрики интерфейса.
- Microsoft [Get-NetAdapterStatistics](https://learn.microsoft.com/en-us/powershell/module/netadapter/get-netadapterstatistics): счётчики реального трафика/ошибок адаптера.
- Microsoft [Get-NetUDPEndpoint](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-netudpendpoint), [MIB_UDPROW_OWNER_PID](https://learn.microsoft.com/en-us/windows/win32/api/udpmib/ns-udpmib-mib_udprow_owner_pid): доступные поля UDP — локальная конечная точка и владелец, не измеритель игрового RTT.
- Microsoft [Suspend-BitsTransfer](https://learn.microsoft.com/en-us/powershell/module/bitstransfer/suspend-bitstransfer), [Resume-BitsTransfer](https://learn.microsoft.com/en-us/powershell/module/bitstransfer/resume-bitstransfer): пауза и асинхронное возобновление; без AllUsers выборка относится к текущему пользователю.
- Cloudflare [WARP modes](https://developers.cloudflare.com/warp-client/warp-modes/) — официальный исходник документации прочитан через [cloudflare-docs](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/docs/warp-client/warp-modes.mdx), [Linux CLI](https://github.com/cloudflare/cloudflare-docs/blob/production/src/content/docs/warp-client/get-started/linux.mdx) — регистрация устройства и MASQUE/WireGuard; [условия](https://www.cloudflare.com/application/terms/) доступны пользователю для самостоятельного чтения, из окружения получен 403.

## Проверки

Локально: TypeScript/Vite, весь набор Node-тестов, новый контроллер с изолированными зависимостями (нет согласия, уже запущенная игра, ошибка запуска, выход, таймаут, восстановление после сбоя и его повтор), сравнение разных целей/интерфейсов, отсутствие ICMP, реальная production-логика журнала BITS под PowerShell с подменёнными провайдерами, браузерные сценарии обеих тем и узкого окна.

GitHub Actions: Windows PowerShell 5.1, те же проверки восстановления, реальные чтения адаптера/реестра/процессов и две серии ICMP на одноразовом Windows Server runner, затем NSIS/portable и проверка Windows-ресурсов. Это не запуск PUBG/Fortnite/Tarkov и не физический ПК с Windows 10/11.

На ПК пользователя ещё проверяются реальные пути Steam/Epic/BSG, авторизация в их лаунчерах, запуск и завершение игр, Wi-Fi-драйвер, наличие собственных BITS-загрузок и их возобновление при принудительном закрытии GTM PC. Прирост игрового RTT в этом окружении не проверялся и не заявляется.
