# Бесплатный игровой маршрут без аккаунтов: проверка 3 ноября 2026

**Рабочий сценарий входа в Fortnite одним нажатием пока не получен.** Доступного подтверждённого узла, удовлетворяющего всем условиям, на этой проверке нет. Это ограничение инфраструктуры; диагностика, DNS, запуск Epic и установка драйвера его не заменяют.

В 0.16.1-beta.1 из «Пинг» удалены форма Proton, установка WireGuard пользователем, импорт .conf, согласие на старый профиль, выбор режима диагностики и панели «оптимизации». Оставлены Fortnite, пока неактивные PUBG/Tarkov, недоступная кнопка подключения, статус и отключение собственного старого соединения. Ни один сохранённый режим из 0.15/0.16 не обходит запрет в основном процессе. Игра не запускается под видом рабочего бустера. Старый компонент оставлен только для восстановления собственных прежних WireGuard-служб; импорт и новое подключение через него из раздела невозможны. Установленные пользователем компоненты и его сохранённые файлы не удаляются.

### Подробность сбоя Riseup

`provider.json` и официальный `ca.crt` доступны по HTTPS. Объявленный SHA-256 CA совпадает с загруженным: `dd919b7513b4a1368faa20e38cd3314156805677f48b787cdd9b4a92dec64eb0`. Его срок закончился **02.11.2026 19:10:37 UTC**, до испытаний. Та же CA опубликована обоими официальными адресами и находится в зеркале LEAP. Официальный публичный статус Riseup при этом показывает Operational; он не заменяет проверку TLS.

Проверены реальные UDP/TLS handshakes двух опубликованных узлов штатным OpenVPN из подписанного репозитория Ubuntu. Использован `dev null`, без изменения маршрутов, DNS и сетевых настроек runner. До передачи пользовательского трафика дело не дошло. Проверка сертификатов не отключалась, дата системы не подменялась. Ошибка совпадает на двух узлах; остальные 19 не проверялись. Анонимные клиентские ключи создавались провайдером для этой проверки, хранились только во временном закрытом каталоге и удалены, в логи/артефакты не экспортировались.

Сертификаты клиентов и серверов могут иметь разных издателей: несовпадение клиентского сертификата с серверной CA само по себе не было принято за доказательство сбоя. Основание блокировки — реальная ошибка проверки серверной цепочки при OpenVPN handshake и срок опубликованной CA.

К компьютеру пользователя доступа нет; Creative, обычный матч и игровой UDP через GTM не проверены, рабочая сборка бустера не заявляется.

## Минимальное условие продолжения

Для Riseup нужен актуальный официальный CA/серверная цепочка и успешная строгая TLS/UDP-проверка, затем реализация и проверка автоматического Windows-компонента, маршрутов Epic/игры/DNS/IPv6 и восстановления. Альтернатива — официально разрешённый другой бесплатный провайдер либо соглашение GearUP, которое даёт приложению и его пользователям доступ без оплаты и ручной регистрации. Пользователь не должен получать ключи или искать сервер. Исправление CA провайдером ещё не гарантирует доступ Epic с его выходных IP — это потребует отдельного испытания Creative и обычного матча на нужном подключении.

Новые аккаунты, чужие ключи, случайные прокси, платные API, аренда и пробные периоды не используются. Обращений к провайдерам от имени пользователя не отправлялось.
