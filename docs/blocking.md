# Блокировки — GTM PC 0.21.0

Раздел содержит два отдельных механизма: Zapret 1.10.4 для сервисов и адаптированное headless-ядро fnport 0.6.3 для Fortnite. Это работающие локальные сетевые компоненты, а не VPN, удалённый узел или обещание снижения пинга. Возможность обхода зависит от провайдера и вида ограничения.

## Как пользоваться

1. Закройте игру перед подбором или сменой режима. Откройте «Блокировки».
2. Для Discord/YouTube нажмите «Подобрать стратегию». Windows запросит права для отдельного сетевого компонента. Приложение сравнит 22 исходные стратегии. Можно включить выбранную стратегию вручную.
3. Для Fortnite сначала нажмите «Проверить провайдера». Проверка fnport использует STUN, маяки Epic и проверки HTTPS сервисов; может занять несколько минут. Подходящие рекомендации фейка/TTL сохраняются автоматически. Повторная проверка ограничена паузой в три минуты, как в исходном fnport.
4. Нажмите «Включить для Fortnite», затем запустите игру через Epic и проверьте обычный матч и Creative. Работа адаптера и ответы маяков не считаются подтверждением входа в матч.
5. «Отключить» останавливает соответствующий механизм. При выходе GTM PC завершает свои компоненты.

В настройках доступны все 22 стратегии, игровой фильтр TCP/UDP, IPSet из исходного архива, три исходных фейка fnport и TTL. Изменения сохраняются между запусками. Сам обход автоматически при запуске приложения не включается. Игровой фильтр Zapret и fnport одновременно не разрешены. Настройки WARP, импорт VPN и регистрация аккаунтов в этот раздел не переносились.

## Подбор Zapret

Исходный архив пользователя по содержимому совпал с официальным релизом Flowseal 1.10.4. `.bat`-меню не исполняются. Из них при сборке извлекаются исключительно фиксированные аргументы winws; вызовы обновления, регистрации автозапуска, удаления других служб и прочие команды меню не выполняются. Сохраняются все 22 стратегии и списки. Пустой игровой фильтр, как в оригинале, заменяется на неиспользуемый порт 12; полный диапазон — только при явном выборе.

Подбор сначала измеряет те же четыре фиксированные публичные HTTPS IPv4 цели без Zapret (Discord API/CDN, страница YouTube и изображение YouTube). Затем каждый профиль проверяется двумя сериями. Проверяются сертификат TLS, ожидаемый HTTP-код и минимальная длина ответа; тайм-ауты, ошибки TLS, HTTP 403 и слишком короткие ответы не считаются успехом. Лучшая стратегия включается только после повторной серии с большим числом успешных ответов, чем без Zapret. При отсутствии улучшения или отмене возвращается прежний режим. В таблице показаны адрес, метод, HTTP-результат и полное время запроса — это не игровой пинг.

Эти проверки не подтверждают QUIC-видеопоток, голос Discord или игровые пакеты. Если все HTTPS-цели доступны без Zapret, программа сообщает об этом вместо фиктивного выбора. Для проблем только с голосом/видео можно пробовать исходные стратегии вручную и проверять соответствующий сервис. Если во время подбора запущена игра, дальнейшие смены блокируются; текущий режим сохраняется до действий пользователя, чтобы не менять сеть посреди матча.

## fnport

Сетевой код взят из официального тега v0.6.3, коммит `855eb018c116c7838a5d0229a1eef3001e6e25dd`. Из него собран отдельный компонент без Gio-окна и трея. Алгоритмы проверки UDP, исходящих портов, TTL, запасных фейков и спасения замёрзших потоков сохранены. WARP выключен и не настраивается; регистрация и ключи не запрашиваются. Поддерживаемые настройки ограничены встроенными фейками и TTL 1–9.

На Windows создаётся собственный временный адаптер `fnport-GTMPC-<PID>` через подписанный Wintun. Как в оригинале, IPv4 трафик к шести диапазонам AWS Europe направляется в этот адаптер; игровой UDP 9000–9999/15000–15999 использует проверенные исходящие порты. TCP и прочий UDP к этим диапазонам проходят через встроенный стек напрямую. Внешний VPN и отдельно запущенный fnport нужно выключить вручную; GTM PC их не завершает.

Это не раздельное туннелирование по процессу. Другие приложения, обращающиеся к этим IPv4 диапазонам, тоже используют локальный адаптер. IPv6 через fnport не обрабатывается, DNS Windows не меняется. Когда роутер/CGNAT меняет исходящий порт или применён другой тип ограничения, fnport может не помочь; проверка сохраняет различие между «не отвечает», «заморозка» и обычными потерями. Счётчики соединений — фактические счётчики ядра, а не подтверждение матча или снижения задержки.

## Права и восстановление

Открытие страницы и чтение статуса не требуют администратора и не запускают перехват. UAC появляется при первой сетевой операции для отдельного PowerShell-супервизора. Всё приложение не повышается. Команды имеют фиксированный набор действий и проверяются основным процессом и супервизором; произвольные программы/команды из интерфейса не принимаются.

Каждый дочерний процесс заключён в отдельный Windows Job Object с kill-on-close. Завершаются только собственные процессы, не все `winws`/VPN по имени. Супервизор проверяет PID/время старта GTM PC и heartbeat: при закрытии, ошибке или потере связи останавливает свои компоненты. fnport закрывает временный адаптер вместе с добавленными на него маршрутами; ОС также освобождает его при завершении дочернего процесса. Исходные DNS/маршруты физических адаптеров и реестр сети не переписываются.

WinDivert не захватывается, если его служба принадлежит другой установке. Для своего драйвера очистка проверяет точный путь, отсутствие других известных пользователей драйвера и остановленное состояние; чужие службы не удаляются. После аварии собственный оставшийся драйвер узнаётся по пути пакета. Если Windows или античит блокирует компонент, приложение показывает ошибку; защиту, подписи драйверов и античит не отключает. EAC может остановить WinDivert: для игрового UDP Fortnite предназначен fnport, а не игровой фильтр Zapret.

Отчёт сохраняется пользователем локально через диалог. Отправки на сервер нет. Он содержит версии, результаты публичных проверок и технические счётчики, не авторизационные данные; fnport маскирует IP в диагностических строках.

## Источники и лицензии

`shared/blocking-components.json` закрепляет официальные URL и SHA-256 архивов. Wintun дополнительно сверяется с SHA-256 из официального build.sh fnport. При сборке и запуске проверяется целостность компонентов; Windows CI проверяет подписи Wintun и WinDivert. Пользователю не нужны Go, Python, ручные скачивания или команды.

В поставку входят MIT-лицензии fnport и zapret, лицензии Go-зависимостей, лицензия Wintun, LGPL/GPL WinDivert и лицензии Cygwin. Рядом находятся соответствующие исходники Cygwin 3.4.10, WinDivert 2.2.2 и fnport 0.6.3. Наши адаптации доступны в `native/blocking`, `scripts/prepare-blocking.py`, `electron/blocking-*`. Меню Flowseal, меняющее внешние службы, не поставляется.

## Проверки

Node-тесты проверяют валидацию параметров, HTTPS-ошибки и тайм-ауты, выбор только по измеренным результатам, повторное подтверждение и восстановление при отмене. Тесты исходного Go-ядра проверяют обработку потоков, QoS, отчёты, сетевые утилиты. Chromium проверяет обе темы, управление, отмену, счётчики и сохранение отчёта на управляемом native bridge.

На одноразовом Windows runner выполняются компиляция рабочего супервизора, проверка подписей, self-test headless-ядра, реальный запуск WinDivert на изолированном неиспользуемом TCP порту, создание/удаление Wintun и остановка при потере heartbeat. Упаковка сверяется по манифесту хэшей. Эти проверки не подтверждают обход на подключении пользователя и не подтверждают вход в Fortnite. Проверка Creative, обычного матча, голоса и видео требует ПК и подключения пользователя.
