# LAGOPHONE 0.2.0

Настольное приложение для Windows 10/11 x64: сведения о ПК, автоматические профили настройки Windows с откатом, каталог приложений и официальная поддержка драйверов. React + TypeScript + Electron + Windows PowerShell 5.1.

## Скачать обычное приложение

Откройте [Actions → Build Windows application](https://github.com/73skrxll-cmd/LAGOPHONE/actions/workflows/windows-app.yml), выберите **последнюю** сборку и дождитесь зелёной галочки. Внизу страницы сборки, в **Artifacts**, скачайте **LAGOPHONE-Windows-x64**. Распакуйте скачанный ZIP:

- **LAGOPHONE-Setup-0.2.0-x64.exe** — установка для текущего пользователя с ярлыками в меню «Пуск» и на рабочем столе. Удаление — через список приложений Windows.
- **LAGOPHONE-Portable-0.2.0-x64.exe** — один файл для запуска без установки, runtime распаковывается во временную папку.

**Node.js, npm и START-WINDOWS.cmd конечному пользователю не нужны.** При применении или откате профиля Windows отдельно запросит права администратора (UAC). Установщики пока без цифровой подписи. Артефакты приватного репозитория доступны авторизованным пользователям с доступом и хранятся 30 дней. Повторная сборка: **Run workflow**.

## Автоматические профили

В разделе **Твики**:

1. Выберите базовый, средний или глубокий профиль.
2. Сохраните галочки у функций, которыми пользуетесь. По умолчанию **все функции сохраняются**. Ответы запоминаются локально.
3. При необходимости выберите план питания и игру. Для персональной настройки GPU укажите основной EXE игры через системный диалог.
4. Просмотрите список изменений, исключите ненужные пункты и нажмите **Оптимизировать**. Подтвердите список и запрос Windows.
5. Прочитайте отчёт: применённые, пропущенные, восстановленные и ошибочные пункты отображаются отдельно. Кнопка **Вернуть как было** восстанавливает сохранённые значения.

### Состав

| Профиль | Изменения |
| --- | --- |
| Базовый | Включение игрового режима, отключение прозрачности. Никаких отключений служб. |
| Средний | Дополнительно анимация сворачивания; Game DVR, Spooler, bthserv и Fax отключаются только при ответе «не пользуюсь». |
| Глубокий | Дополнительно WSearch, MapsBroker, WMPNetworkSvc, RemoteRegistry — тоже только по ответам пользователя. |

**SysMain** — отдельная экспериментальная опция только глубокого профиля, по умолчанию выключена и не запоминается. Отключение предварительной загрузки может ухудшить запуск приложений; это не универсальная оптимизация. Отключение Spooler затрагивает **Microsoft Print to PDF**, Bluetooth — беспроводные устройства, WSearch — индексируемый поиск и Outlook. Последствия каждого действия показаны до выполнения.

Планы питания: текущий, сбалансированный, высокая или максимальная производительность. Переключаются только существующие штатные GUID. Если план недоступен (например, на Modern Standby), операция пропускается; скрытые планы не создаются. Высокая производительность может увеличить нагрев, шум и расход батареи.

Профили CS2, VALORANT, Fortnite, Dota 2 и Apex Legends задают **только предпочтение производительного GPU для выбранного EXE** плюс выбранные общие настройки Windows. Другие графические предпочтения этого EXE сохраняются. Автоматического редактирования файлов игры, приоритетов защищённых процессов, таймеров, CPU affinity, сетевого стека или драйверов нет. Предпочтение GPU может не повлиять на ПК с одной видеокартой; название игры само по себе не означает измеренный прирост производительности.

### Совместимость

Приложение не отключает Defender, Windows Update, Store, Gaming Services, Xbox Live, Secure Boot, TPM, VBS, FACEIT или Vanguard. Отключение Game DVR не удаляет Game Bar и Xbox: запись клипов станет недоступной, сама панель остаётся. Зависимые работающие службы не останавливаются каскадно, служба с активными зависимостями пропускается. Отсутствующие службы также пропускаются. Точные версии Windows сверяются перед применением.

Это ограничение области изменений, **не гарантия совместимости со всеми играми и античитами**. Производительность и совместимость необходимо проверять на реальном оборудовании. Отключение простаивающей службы может не дать измеримой экономии ресурсов.

### Резервная копия и отказоустойчивость

До первого изменения исходные значения сохраняются в `%ProgramData%\LAGOPHONE\optimization-state.json`. Каталог защищается правами Administrators/SYSTEM, обычным пользователям разрешено чтение. Сохраняются наличие, тип и значение реестра, режим запуска и состояние службы, отложенный автозапуск, исходный план питания. Изменения HKCU адресуются через **SID исходного пользователя в HKU**, в том числе при подтверждении UAC другой администраторской учётной записью.

Каждый результат проверяется после записи. При ошибке выполняется попытка отката всего сохранённого плана. При неполном восстановлении журнал сохраняет нерешённые пункты для повторной попытки. После аварийного завершения журнал обнаруживается при следующем запуске. Новый профиль нельзя применить поверх активного журнала. Конфликтующие значения реестра и планы питания, изменённые сторонними программами, не перезаписываются молча. Служба восстанавливается только из отключённого или исходного режима запуска.

Резервная копия параметров — **не точка восстановления Windows и не резервная копия файлов**. Пустые созданные разделы реестра могут остаться; исходные значения и их отсутствие восстанавливаются. Последний отчёт сохраняется в `last-optimization.json` внутри каталога пользовательских данных Electron. Не удаляйте журнал до отката. Пока идёт операция, закрытие окна и параллельные изменения из приложения блокируются.

Очистка TEMP старше семи дней и ручные средства Windows доступны отдельно в **Дополнительных инструментах**. Очистка необратима и не входит в обратимый автоматический профиль.

## Индикатор и темы

Плашка на главной странице и в разделе твиков оценивает **соответствие проверяемых настроек**, а не быстродействие ПК: основные параметры плюс фактическое состояние сохранённых изменений. Пропущенные действия смотрите в отчёте. Нет выдуманного процента FPS. В деморежиме или при ошибке чтения оценка не выставляется; незавершённый ошибочный профиль требует отката.

В верхней панели и на экране выбора ОС находится переключатель **Тема**: зелёная, красная, синяя, чёрная и фиолетовая. Выбор сохраняется локально. Темы меняют акцент и поверхности, а не только одну кнопку.

## Другие разделы

**Система:** CIM-информация о CPU, GPU, плате, ОЗУ, дисках, ОС и времени работы. В браузере и на Linux явно показаны демоданные, системные операции не выполняются.

**Приложения:** Discord, NanaZip, qBittorrent, Steam, Mem Reduct, VS Code, Firefox, VLC. Прямое сохранение установщиков Discord, Steam, VS Code, Firefox; для остальных — официальный сайт. Установщики автоматически не запускаются. Mem Reduct нужен не всем ПК и не гарантирует ускорение.

**Драйверы:** обнаружение NVIDIA/AMD/Intel и известных OEM, ссылки на официальную поддержку. Версии драйверов не сравниваются, драйверы автоматически не устанавливаются. Модель и ОС необходимо сверить на сайте производителя.

## Разработка

Node.js **24 LTS**. На Windows из папки исходников:

```powershell
npm ci
npm run desktop
```

`START-WINDOWS.cmd` — вспомогательный запуск **для исходников**, требует Node.js. Не используйте его вместо готового EXE.

```sh
npm run dev          # браузерный интерфейс с демоданными
npm run build        # TypeScript + production Vite
npm test            # проверки политики и профилей, Windows-тесты на Windows
npm run dist:win -- --publish never
npm run dist:portable -- --publish never
```

В облачной Linux-среде для установки зависимостей через штатный прокси: `NODE_USE_ENV_PROXY=1 npm ci --no-audit --no-fund`. Сохраняйте proxy и CA-настройки, не отключайте TLS. NSIS-установщик на Linux требует Wine; предпочтительнее сборка в GitHub Actions на Windows. Worker `electron/optimizer.ps1` распаковывается из ASAR отдельно для запуска Windows PowerShell. Узкий IPC не принимает произвольные команды и URL, профиль дополнительно проверяется в main process. `ExecutionPolicy Bypass` используется только для процесса нашего worker, системная политика выполнения скриптов не изменяется.

### Проверки

- JavaScript: несовпадение ОС, запрет неизвестных команд, опции профиля, сохранение используемых функций, opt-in SysMain, исключение защищённых служб, список HTTPS-адресов.
- PowerShell: синтаксис worker; настоящий код восстановления с подменой только провайдеров проверяет отсутствие исходного значения, незавершённое применение, внешние конфликты, повторный откат, подменённый журнал, отложенный автозапуск и план питания. Этот тест выполнен в Linux на официальном PowerShell с проверенной SHA-256.
- Chromium: пять тем и их сохранение, профили и вопросы, согласие, демоблокировка, узкий экран, обработка результата/индикатор/откат с подставным native bridge. Подставной bridge не доказывает выполнение Windows-команд.
- Windows CI: PowerShell 5.1 и применение/точный откат пользовательских настроек реестра на одноразовом runner. Настоящие изменения выполняются **только** при `LAGOPHONE_WINDOWS_INTEGRATION=1`; не включайте этот флаг на повседневном ПК для запуска тестов.

Локально в Linux Windows-тесты явно пропускаются. Успешность конкретного Windows-run нужно проверять в Actions; локальная сборка не подтверждает её. Полная проверка отключения служб, UAC, обоих выпусков Windows 10/11 и совместимости с играми требует отдельных Windows-машин.
