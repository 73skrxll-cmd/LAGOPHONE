# LAGOPHONE

Настольная утилита для Windows 10/11 x64 на Electron, React и TypeScript. Тёмный интерфейс с зелёными акцентами, выбором ОС, обзором комплектующих, системными инструментами и каталогом приложений.

## Обычное приложение — без Node.js

Для пользователя предназначены два файла:

- `LAGOPHONE-Setup-0.1.0-x64.exe` — мастер установки. По умолчанию устанавливает приложение для текущего пользователя, создаёт ярлыки на рабочем столе и в меню «Пуск». После установки запускать нужно ярлык **LAGOPHONE**. Удаление доступно в настройках приложений Windows.
- `LAGOPHONE-Portable-0.1.0-x64.exe` — самостоятельный запуск без установки. При старте распаковывает встроенный runtime во временную папку; первый запуск может занять больше времени.

Обе версии содержат всё необходимое для работы: Node.js, npm, консоль и `START-WINDOWS.cmd` пользователю не нужны. Интернет нужен для скачивания приложений и перехода на сайты поддержки, но не для установки npm-зависимостей при запуске.

### Получить сборку через GitHub

В репозитории откройте **Actions → Build Windows application**. Сборка запускается автоматически при обновлении приложения в main. Дождитесь зелёной отметки завершения. Откройте выполненную сборку, внизу в разделе **Artifacts** скачайте **LAGOPHONE-Windows-x64**, распакуйте ZIP и запустите файл `LAGOPHONE-Setup-…exe`. Повторный запуск: **Run workflow → Run workflow**. Для скачивания артефактов приватного репозитория нужно войти в GitHub с доступом к нему. Срок хранения артефакта — 30 дней; сборку можно запустить повторно.

Workflow собирает NSIS-установщик и portable EXE на Windows, запускает тесты и добавляет SHA-256. Он не публикует релиз автоматически. Локальная сборка в Linux не заменяет проверку установки и системных функций на настоящей Windows. Файлы не имеют цифровой подписи.

## Запуск исходников в Windows (для разработки)

Установите Node.js 24 LTS, откройте PowerShell в каталоге проекта:

```powershell
npm ci
npm run desktop
```

Обычного запуска достаточно для чтения характеристик и пользовательских настроек. Штатные инструменты Windows могут отдельно запросить повышение прав. Приложение целиком не требует запуска от администратора.

Сборка установщика на Windows:

```powershell
npm run dist:win
```

Результат находится в `release/`. Подпись установщика не настроена; Windows может показать предупреждение SmartScreen. Windows-установщик в Linux-среде разработки не собирался и не проверялся.

### Готовый ZIP для Windows x64

Архив `release/LAGOPHONE-0.1.0-win.zip` собран в Linux с помощью electron-builder. Распакуйте **весь** архив в отдельную папку и запустите `LAGOPHONE.exe` внутри неё. Node.js на целевом ПК не нужен. Не переносите EXE отдельно от остальных файлов. Это неподписанная предварительная версия; выполнение системных функций на Windows пока не проверено.

Повторная сборка ZIP:

```sh
npm run build
npx electron-builder --win zip --x64 --config.win.signAndEditExecutable=false
```

## Разработка и предпросмотр

```sh
npm ci
npm run dev
```

В браузере и при запуске Electron на Linux показывается **явно обозначенный демонстрационный набор характеристик**. Доступ к ПК и сохранение установщиков через браузер не выполняются. Не вводите данные демонстрационной конфигурации как характеристики реального компьютера.

В управляемой облачной среде с Node.js 24 и HTTPS-прокси используйте `NODE_USE_ENV_PROXY=1 npm ci` для загрузки Electron. Сохраняйте штатные proxy-переменные и проверку TLS. Для Windows без прокси эта переменная не нужна.

```sh
npm run build
npm test
```

Проверки тестируют запрет неизвестных системных команд, несовпадение выбранной Windows и каталог разрешённых HTTPS-адресов. Браузерный сценарий также проверен: выбор обеих ОС, четыре раздела, подтверждение действия, запрет действий в деморежиме, поиск, пустая выдача, сброс фильтров и узкая ширина экрана. Запуск PowerShell и загрузка реальных установщиков требуют отдельной проверки на Windows 10 и 11.

## Что реализовано

- **Система:** Windows CIM / PowerShell — процессор, ядра, потоки, видеокарты, плата, ОЗУ, физические диски, версия ОС и время работы. Название производителя компьютера используется для определения OEM-поддержки. При ошибке чтения интерфейс сообщает об этом и явно переключается на демоданные.
- **Твики:** удаление файлов из пользовательского TEMP старше 7 дней (занятые файлы пропускаются); отключение и включение прозрачности; переходы в автозагрузку, список программ, службы, игровой режим, контроль памяти, защиту системы и оптимизацию дисков. Windows сама выбирает подходящий вид оптимизации накопителя. Все текущие действия поддерживают Windows 10 и 11; перед выполнением фактическая ОС сравнивается с выбранной.
- **Каталог:** Discord, NanaZip, qBittorrent, Steam, Mem Reduct, VS Code, Firefox и VLC. Прямая загрузка Discord, Steam, VS Code и Firefox с выбором места сохранения и прогрессом. Для остальных открывается официальный сайт: нестабильные ссылки на файлы не зашиты в приложение. Загрузки идут только по фиксированным адресам каталога, автоматически не запускаются; частичные файлы удаляются после неудачи. Установщики x64.
- **Драйверы:** определение NVIDIA / AMD / Intel и известных производителей плат/ПК, переходы на официальную поддержку, ссылки на Visual C++, DirectX и .NET. На сайте необходимо выбрать точную модель и ОС. Автоматической проверки устаревания драйвера и автоматической установки драйверов нет. В список не добавляются случайные драйверы неизвестного оборудования.

## Границы и безопасность

Нет универсального безопасного списка «ненужных» служб, поэтому приложение не отключает их пакетно. Удаление программ выполняется пользователем через Windows. Очистка TEMP необратима; настройки прозрачности можно вернуть кнопкой «Вернуть» (она включает прозрачность, а не восстанавливает произвольный предыдущий реестр). Точки восстановления создаются пользователем через штатный диалог. Mem Reduct не гарантирует ускорения и нужен не всем системам. Новые твики следует добавлять в явный список `electron/policy.cjs` с проверкой совместимости и отдельным тестом.

Renderer изолирован: `contextIsolation`, sandbox, отключённый Node.js, CSP в production и узкий IPC API. Произвольные команды и URL из интерфейса не принимаются. Драйверы и установщики не выполняются автоматически. Приложение не отключает Defender, обновления Windows, телеметрию или критичные службы. Выигрыш FPS не обещается.
